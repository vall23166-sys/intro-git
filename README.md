# Mi primer repositorio

En este miniproyecto he aprendido los siguientes comandos:
- `git clone`
- `git log` con los modificadores `--oneline y --all`
- `git checkout`
- `git diff`
- `git add .`
- `git commit -m "mensaje"`
- `git remote, incluyendo get-url y set-url`
- `git merge, para arreglar una cosita`
- `git push`

## Más cosas de markdown
Podemos formatear código usando triple comilla + el nombre del mensaje:
```java

    System.out.println("Hola, markdown");
}
```
